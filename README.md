# OpenDoc Pakistan Datasets

Clean, documented, AI/ML-ready datasets focused on Pakistan.

Each dataset lives in `datasets/<dataset_name>/` and includes:

- `README.md` dataset card
- `datapackage.json` metadata
- `data_dictionary.csv` schema documentation
- `data/processed/` cleaned machine-readable files
